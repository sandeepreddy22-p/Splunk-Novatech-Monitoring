# Multi-Source Data Onboarding Guide

# 1. Windows Logs Onboarding
* Configured Windows inputs to ingest Security, System, and Application event logs using the Splunk Add-on for Windows.

# 2. Linux Logs Onboarding
* Configured `inputs.conf` to monitor standard system log paths (`/var/log/syslog`, `/var/log/auth.log`).

# 3. ServiceNow Integration
* Onboarded incident management and change request telemetry data into Splunk for IT service monitoring.

# 4. Syslog Integration
* Set up network syslog collection for infrastructure devices.

# 5. AWS Cloud Logs
* Integrated AWS CloudTrail and CloudWatch log streams using the AWS Add-on for Splunk.
